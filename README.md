# Winnipeg Confessions

A mobile-first starter website for an anonymous confession page.

## Included
- Public confession feed
- Anonymous submission form
- Automatic sequential confession numbers
- Local demo moderation dashboard
- Black + gold visual theme
- Community rules page

## Production Instagram automation
The demo's **Approve & Post** action is intentionally a front-end placeholder. For real automatic Instagram publishing, connect it to a secure server/backend that:
1. receives the approved confession;
2. generates the square/portrait branded graphic;
3. uploads the media to Meta/Instagram using an eligible Professional Instagram account and the appropriate Meta permissions;
4. publishes the media container;
5. stores the resulting Instagram media ID/URL.

Never put Meta access tokens in browser JavaScript.
